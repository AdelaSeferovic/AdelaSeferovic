## Featured Project — Maturix Monitor

A full-stack monitoring dashboard built for a real company called Maturix.

## The Problem
Maturix collects large amounts of data from their customers' gateways 
(base stations) — but none of it was being used. This created an 
operational "black hole" causing:
- Inefficient troubleshooting
- Increased pressure on the support team
- Missing information for customers
- Undetected operational issues

### The Solution
A web platform where Maturix and their customers can monitor 
gateway health, SIM information, and device status in one place.

### My Role
I am independently building the full-stack version of this platform 
to deepen my understanding of how frontend and backend communicate.

### Tech Stack
- **Frontend:** React, Vite, Axios
- **Backend:** Node.js, Express, MongoDB, Mongoose
- **Other:** REST API, Git, GitHub

### What I built
- REST API with Express following MVC architecture
- MongoDB database with Mongoose schemas and data validation
- Gateway status endpoints returning real-time data
- React frontend consuming the API
